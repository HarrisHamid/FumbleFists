# FumbleFists

Failed the exam? Throw hands (fictionally). A just-for-fun, single-player swipe-to-spar parody built with Expo. All fighters are made up and everything is stored on your phone.

## Getting started

```bash
bun install
bun run start
```

Then scan the QR code with **Expo Go** on your phone (phone and Mac on the same Wi-Fi). If the phone can't connect (hotspot, VPN, campus Wi-Fi), use `bun run start:tunnel` instead. `bun run web` gives a quick browser preview.

## Checks

```bash
bun run typecheck
bun run lint
bunx expo-doctor
```
